Feature Importance
==================

The v2 feature importance module provides functions for analyzing how
different input variables affect model results.

Analyzing a Missing Input
-------------------------

``analyze_missing_input()`` evaluates the effect of a missing input on
the model's damage estimates.

Comparing Missing Inputs
------------------------

``compare_missing_inputs()`` allows the results of multiple missing-input
analyses to be compared.

Ranking Missing Inputs
----------------------

``rank_missing_inputs()`` ranks missing inputs based on the results of
the analysis.

Why Feature Importance Matters
------------------------------

Understanding which inputs have the greatest influence on estimated
damage can help identify important data collection priorities.

Module Reference
----------------

For function arguments, return values, and analysis behavior, see


pyINSYDE Documentation
======================

Python implementation and extensions for the INSYDE flood damage model.

Welcome
-------

pyINSYDE is a Python-based implementation of the INSYDE building flood
damage model.

The project estimates monetary damage to buildings based on building
characteristics and flood hazard conditions.

The v2 package extends the original implementation with additional
functionality for:

* Input validation
* Probability distributions
* Missing input handling
* Uncertainty analysis
* Feature importance
